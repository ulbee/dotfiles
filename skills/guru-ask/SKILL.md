# DMP: задать вопрос

## Когда применять

Скилл активируй для вопросов про `dmp_suite`, архитектуру DWH, таски и таблицы — без создания нового кода по workflow.

## Источники в этом скилле

- Полный сценарий: [command.md](command.md).

Остальные документы (`docs/memory_bank/`, `docs/dmp_suite_doc/`) — только в дереве проекта.

## Обязательные действия агента

1. Определи тему вопроса и прочитай релевантные файлы из `docs/memory_bank/` и при необходимости `docs/dmp_suite_doc/`.
2. Согласуй термины и ограничения с общими правилами dmp_suite (окружение, YT/GP read-only и т.д.).
3. Не выдумывай поведение фреймворка — если не нашёл в документации, честно скажи.
4. Ответы пользователю — **на русском**.
