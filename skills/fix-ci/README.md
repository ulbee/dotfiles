# fix-ci

Диагностика и исправление неудачных CI checks на Arcanum PR. Получает статусы проверок, анализирует логи Sandbox, применяет исправления.

## Использование

Вызывается как скилл `/fix-ci PR_ID`.

## Зависимости

- `arcanum-cli.sh` — получение checks и PR данных
- `sandbox-cli.sh` — получение логов и ошибок из Sandbox

## Что умеет

- Определяет тип ошибки (формат, тесты, сборка, merge conflict, outdated branch)
- Получает и парсит логи из Sandbox
- Применяет исправления в коде
