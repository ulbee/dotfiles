# DMP: создать таблицу

## Когда применять

Скилл активируй, когда нужно описать новую таблицу в `dmp_suite` через DSL и `table.py`.

## Источники в этом скилле

- Полный сценарий: [command.md](command.md).

Документы Memory Bank и `docs/dmp_suite_doc/` — в репозитории dwh; пути указаны в `command.md`.

## Обязательные действия агента

1. Сначала следуй workflow `10-new_table_workflow`.
2. Чеклист прогресса веди через **TodoWrite**.
3. Пользовательский текст — **на русском**.
