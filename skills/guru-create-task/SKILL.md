# DMP: создать таск

## Когда применять

Скилл активируй, когда нужно создать новый ETL-таск в `dmp_suite` по согласованному workflow.

## Источники в этом скилле

- Полный сценарий и шаги: [command.md](command.md).

Документы Memory Bank и `docs/dmp_suite_doc/` не входят в скилл — они лежат в дереве проекта dwh; читай их по путям из команды.

## Обязательные действия агента

1. Сначала следуй workflow `20-new_task_workflow`.
2. Для чеклиста прогресса используй инструмент **TodoWrite** (как в `command.md`).
3. Весь пользовательский текст — **на русском языке**, как в исходной команде.
